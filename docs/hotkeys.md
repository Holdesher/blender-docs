# Hotkeys

## Navigation

| Клавиша              | Описание                                                                   |
| -------------------- | -------------------------------------------------------------------------- |
| `0`                  | Переключить на камеру / выйти из камеры                                    |
| `1-9`                | Режимы вида                                                                |
| `~`                  | Меню переключения вида (сверху, снизу, слева, справа и т.д.)               |
| `/`                  | Локальный вид - изоляция выделенного объекта для детального редактирования |
| `Home`               | Показать все объекты сцены                                                 |
| `,`                  | Меню ориентации трансформации                                              |
| `Mouse3`             | Вращение камеры вокруг 3D-курсора                                          |
| `Ctrl + Mouse3`      | Панорамирование (передвижение по прямой)                                   |
| `Ctrl + Alt + 0`     | Поставить камеру по текущему viewport                                      |
| `Shift + ~`          | Режим облёта камеры (fly/walk navigation)                                  |
| `Ctrl + Alt + Space` | Focus Mode - полноэкранный режим без отвлекающих элементов                 |

---

## Transform

| Клавиша               | Описание                                      |
| --------------------- | --------------------------------------------- |
| `G` (`X` / `Y` / `Z`) | Перемещение объекта - свободно или по оси     |
| `R` (`X` / `Y` / `Z`) | Вращение объекта - свободно или по оси        |
| `S` (`X` / `Y` / `Z`) | Масштабирование объекта - свободно или по оси |

> Зажмите ось после нажатия клавиши: `G` → `X` - перемещение только по оси X.

---

## Overlay

| Клавиша             | Описание                                       |
| ------------------- | ---------------------------------------------- |
| `W`                 | Переключение типов курсоров выделения          |
| `Shift + ЛКМ`       | Мульти-выделение (добавить к выделению)        |
| `Alt + W`           | Меню инструментов выделения                    |
| `Alt + ЛКМ`         | Выделение цепочки рёбер _(Edit Mode)_          |
| `Alt + Ctrl + ЛКМ`  | Выделение цепочки граней _(Edit Mode)_         |
| `Alt + Shift + ЛКМ` | Выделение цепочки рёбер и граней _(Edit Mode)_ |
| `Ctrl + "+" / "−"`  | Расширить / сузить выделение _(Edit Mode)_     |

---

## Control

| Клавиша     | Описание                                                   |
| ----------- | ---------------------------------------------------------- |
| `H`         | Скрыть выделенный объект (`Alt + H` - показать скрытые)    |
| `M`         | Удалить объект из локального вида                          |
| `Shift + D` | Дублировать выделенный объект (независимая копия)          |
| `Alt + D`   | Связанный дубликат (изменения в одном отражаются в другом) |

---

## Edit Mode

| Клавиша    | Описание                                                       |
| ---------- | -------------------------------------------------------------- |
| `E`        | Экструдирование - создание новой геометрии от выделенного      |
| `I`        | Inset Faces - вставка граней внутрь выделенных полигонов       |
| `K`        | Нож (Knife) - разрезание геометрии (`Enter` для подтверждения) |
| `Ctrl + R` | Loop Cut - подразделение объекта кольцевым разрезом            |
| `M`        | Меню Merge (объединение вершин)                                |

---

## Menu

| Клавиша              | Описание                                               |
| -------------------- | ------------------------------------------------------ |
| `N`                  | Боковая панель (параметры сцены, объекта, инструмента) |
| `Shift + A`          | Add-меню: объекты _(Layout)_ / ноды _(Shading)_        |
| `Shift + S`          | Меню Cursor (привязка курсора и объектов)              |
| `Shift + Space`      | Меню инструментов текущего режима                      |
| `Ctrl + ~`           | Меню расположения рабочих пространств                  |
| `Shift + Ctrl + Tab` | Меню режимов привязки (snap)                           |

---

## Cursor

| Клавиша       | Описание                                 |
| ------------- | ---------------------------------------- |
| `Shift + C`   | Переместить 3D-курсор в начало координат |
| `Shift + Tab` | Включить / выключить привязку (snap)     |

---

## Animation

| Клавиша     | Описание                                                |
| ----------- | ------------------------------------------------------- |
| `I`         | Вставить ключевой кадр (Insert Keyframe)                |
| `Alt + I`   | Удалить ключевой кадр                                   |
| `Ctrl + →`  | Jump Time - перейти вперёд по таймлайну на заданный шаг |
| `Ctrl + ←`  | Jump Time - перейти назад по таймлайну на заданный шаг  |
| `Space`     | Запустить / остановить воспроизведение анимации         |
| `Shift + ←` | Перейти к первому кадру                                 |
| `Shift + →` | Перейти к последнему кадру                              |

---

## Nodes (Shading / Geometry Nodes)

| Клавиша              | Описание                                         |
| -------------------- | ------------------------------------------------ |
| `Shift + S`          | Swap - замена нод                                |
| `Ctrl + Shift + ЛКМ` | Предпросмотр ноды (Viewer Node)                  |
| `Ctrl + T`           | Добавить Texture Coordinate + Mapping к текстуре |
| `Ctrl + RMB`         | Cut Links - разрезать связи между нодами         |

## Other

| Клавиша            | Описание                                          |
| ------------------ | ------------------------------------------------- |
| `Q`                | Быстрый экспорт (в формат, выбранный в избранном) |
| `Shift + R`        | Repeat Last - повторить последнее действие        |
| `Shift + Z`        | Переключить режим X-Ray                           |
| `Shift + Alt + Z`  | Скрыть всё, кроме объектов (чистый вид)           |
| `Ctrl + N`         | Создание нового проекта                           |
| `Shift + Ctrl + O` | Открыть недавние проекты                          |
| `Tab`              | Переключение между Object Mode и Edit Mode        |
| `Ctrl + Z`         | Отмена действия (Undo)                            |
| `Ctrl + Shift + Z` | Повтор действия (Redo)                            |
| `F2`               | Переименовать выделенный объект                   |
| `F3`               | Поиск команд (Command Search)                     |
| `X` / `Delete`     | Удаление выделенного объекта / элемента           |
| `Ctrl + J`         | Объединить выделенные объекты (Join)              |
| `P`                | Разделить объект (Separate) _(Edit Mode)_         |
| `Ctrl + A`         | Меню Apply (применить трансформации)              |
